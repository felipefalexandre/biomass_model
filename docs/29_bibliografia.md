# 29 — Bibliografia

Lista das referências citadas neste planejamento. Todas as entradas têm identificador verificável
(DOI/PII), exceto onde marcado. Ver `docs/28` para o status detalhado.

**Convenção:** listas de autores são abreviadas como `Primeiro autor, et al.` quando a lista
completa não foi conferida na fonte. Volume/páginas só são incluídos quando confirmados na
verificação; caso contrário, constam apenas periódico e DOI.
