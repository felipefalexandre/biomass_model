## 4. Regra de citação

1. Só citar com DOI/PII confirmado ou fonte oficial verificada.
2. Se parcial, citar como "verificar" e não usar como base única de decisão.
3. Nunca inventar páginas, volumes ou títulos.
4. Atualizar este documento quando a verificação for concluída.

## 5. Como verificar (procedimento)

1. Buscar o DOI em `doi.org` e conferir título/autores/ano.
2. Conferir no site do periódico ou em repositório institucional.
3. Registrar o identificador e a data de verificação.
4. Se divergir, corrigir a entrada e anotar a correção.
